モバイルバッテリー市場で定番モデルとして知られる**Anker PowerCore 10000**。その人気の理由はコンパクトなサイズと使いやすさにあると言われています。本記事では実際の使用感をもとにメリット・デメリットを解説し、Amazon・楽天の価格推移データを活用して最安値で購入する方法を紹介します。

## Anker PowerCore 10000の基本スペック

Anker PowerCore 10000は、米国の人気ガジェットブランドAnkerが販売するモバイルバッテリーです。以下が主な仕様とされています。

| 項目 | 仕様 |
|------|------|
| 容量 | 10000mAh |
| 入力 | Micro USB 5V/2A |
| 出力 | USB-A 5V/2A（×2ポート） |
| 重量 | 約180g |
| サイズ | 約92×60×22mm |

コンパクトなボディに10000mAhの容量を詰め込んだ設計が特徴とされており、スマートフォン(3000mAh程度)であれば約2〜3回のフル充電が可能とされています。重量約180gという軽量さも携帯性の高さに貢献していると言われています。

## 実際に使ってわかったメリット・デメリット

**メリット:**

1. **コンパクトで持ち歩きやすい**: スマートフォンとほぼ同じ大きさで、カバンやポケットに入れても邪魔になりにくいとされています。
2. **2ポート同時充電**: USB-Aが2ポートあるため、スマートフォン2台を同時に充電できます。
3. **品質の安定性**: Ankerブランドの安全管理が行き届いているとされており、長期間使用しても性能が安定しているという声が多いと言われています。
4. **価格帯のコスパ**: 同容量クラスの中では手頃な価格帯に位置することが多いとされています。

**デメリット:**

1. **高速充電非対応**: USB PDには対応していないため、急速充電対応機種でも通常速度での充電となります。急ぎで充電したい場合には物足りなさを感じる可能性があります。
2. **入力がMicro USB**: USB-Cが主流になりつつある現在、Micro USB入力は少し古さを感じさせる場合があります。ケーブルを別途持ち歩く必要があります。
3. **容量表示なし**: 残量をLEDランプ（4段階）で確認する仕様のため、細かい残量がわかりにくいとされています。
